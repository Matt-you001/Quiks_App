# **App Name**: Synapse Trainer

## Core Features:

- Subject Selection: Allow users to choose a subject from a range of options, including Arithmetic, English, Sciences (Physics, Chemistry, Biology), Geography, General Knowledge, and Current Affairs.
- Time Target: The aim is to get the user to finish the test in the fastest possible time and so the app should have an average allocated time for each test. If the user finishes before the App's allocated time, he has a plus in time usage. If the user doesn't finish before the allotted time, the test closes and the result is calculated based on the number of questions the user was able to answer.
- Dynamic Questions: Dynamically generate questions related to the selected subject and deliver them to the user. The questions should be random and auto-generated by the app. The questions can come in an objective form for easy selection and speed.
- Adaptive Testing: Use an AI tool that analyzes user performance to adjust the difficulty, so that the testing is in levels and difficulty should be increased in the next level. All the questions in a level should be of the same level of difficulty. After answering a level, the next level can automatically open for the user if he scores up to 70%. If not, he repeats the level until he scores 70%. A user who has scored up to 70% can choose to repeat that same level or progress to the next level.
- Performance Grading: Grade the user's performance based on the accuracy of answers alone. Users who finish before the set time can be given bonus coins according to the amount of time remaining unused.
- Results Display: Clearly display the results, highlighting accuracy. Display bonus coins earned.

## Style Guidelines:

- Primary color: Indigo (#4B0082), evoking intellect, focus, and calm concentration.
- Background color: Light gray (#F0F0F0), providing a clean and neutral backdrop to minimize distractions.
- Accent color: Teal (#008080), used for highlighting key metrics and interactive elements, encouraging quick user engagement and decisions.
- Body and headline font: 'Inter', a sans-serif with a modern, neutral look, suitable for both headlines and body text.
- Use minimalist icons for subject categories and performance metrics for clarity.
- A clean and distraction-free layout focused on readability and quick response times.
- Subtle, non-distracting animations for transitions and feedback, enhancing the user experience without slowing down response times.
